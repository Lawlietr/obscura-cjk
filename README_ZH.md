Obscura 是以 Rust 撰寫的無頭瀏覽器引擎，為網頁爬取與 AI agent 自動化而設計。它透過 V8 執行真正的 JavaScript、支援 Chrome DevTools Protocol，並可作為 headless Chrome 搭配 Puppeteer 與 Playwright 的直接替代品。

### 為什麼選 Obscura 而不是 headless Chrome？

為大規模自動化而設計，不是桌面瀏覽。

| 指標         | Obscura      | Headless Chrome |
|--------------|--------------|------------------|
| 記憶體       | **30 MB**    | 200+ MB          |
| 二進位大小   | **70 MB**    | 300+ MB          |
| 反偵測       | **內建**      | 無               |
| 頁面載入     | **85 ms**    | 約 500 ms        |
| 啟動         | **瞬間**      | 約 2 秒          |
| Puppeteer    | **支援**      | 支援             |
| Playwright   | **支援**      | 支援             |

## 安裝

### 下載

從 [Releases](https://github.com/h4ckf0r0day/obscura/releases) 取得最新二進位：

```bash
# Linux x86_64
curl -LO https://github.com/h4ckf0r0day/obscura/releases/latest/download/obscura-x86_64-linux.tar.gz
tar xzf obscura-x86_64-linux.tar.gz
./obscura fetch https://example.com --eval "document.title"

# Linux ARM64 (aarch64)
curl -LO https://github.com/h4ckf0r0day/obscura/releases/latest/download/obscura-aarch64-linux.tar.gz
tar xzf obscura-aarch64-linux.tar.gz

# Arch Linux (AUR)
yay -S obscura-browser

# NixOS
nix-env -iA nixpkgs.obscura

# macOS Apple Silicon
curl -LO https://github.com/h4ckf0r0day/obscura/releases/latest/download/obscura-aarch64-macos.tar.gz
tar xzf obscura-aarch64-macos.tar.gz

# macOS Intel
curl -LO https://github.com/h4ckf0r0day/obscura/releases/latest/download/obscura-x86_64-macos.tar.gz
tar xzf obscura-x86_64-macos.tar.gz

# Windows
到 releases 頁面下載 `.zip` 並手動解壓。
```

不需要 Chrome、不需要 Node.js、沒有任何相依。Release 壓縮包同時包含
`obscura` 與 `obscura-worker` 兩個二進位；並列的 `scrape` 命令需要它們
放在同一目錄。

| 檔案後綴   | 渲染  | 隱形傳輸 |
|------------|-------|----------|
| 無         | 有    | 無       |
| `-stealth` | 有    | 有       |
| `-no-render` | 無  | 無       |
| `-no-render-stealth` | 無 | 有 |

Linux release 建置以 Ubuntu 22.04 為目標，讓下載的二進位能在 glibc 2.35+
的常見 LTS 伺服器上直接使用。

### Docker

```bash
docker run -d --name obscura -p 127.0.0.1:9222:9222 h4ckf0r0day/obscura
```

映像檔在 [Docker Hub](https://hub.docker.com/r/h4ckf0r0day/obscura)。多階段建置於 `distroless/cc`，無 shell、無套件管理器，壓縮後約 57 MB。映像檔以 `cjk` feature 建置，CJK 文字開箱即用（見 [CJK 與自訂字型](#cjk-與自訂字型)）。

### 從原始碼建置

```bash
git clone https://github.com/h4ckf0r0day/obscura.git
cd obscura

# 渲染 + 內嵌 CJK fallback 字型（推薦）
cargo build --release -p obscura-cli --bins --features render,cjk

# 只渲染、不含 CJK
cargo build --release -p obscura-cli --bins --features render

# 渲染與 stealth
cargo build --release -p obscura-cli --bins --features render,stealth

# 無渲染
cargo build --release -p obscura-cli --bins --no-default-features

# 無渲染、含 stealth
cargo build --release -p obscura-cli --bins --no-default-features --features stealth
```

`cjk` feature 內嵌 Noto Sans CJK SC/TC（SIL OFL），中文與日文不需系統字型
即可渲染。它為選配，以保持基礎二進位精簡；release 壓縮包與 Docker 映像檔
皆以它開啟的狀態建置。

需要 Rust 1.75+（[rustup.rs](https://rustup.rs)）。首次建置約 5 分鐘（V8 從原始碼編譯，之後有快取）。
stealth 建置另需編譯 BoringSSL 並產生綁定，因此需要
CMake、Clang 與 libclang/LLVM 開發庫。Ubuntu/Debian：

```bash
sudo apt-get install build-essential cmake clang libclang-dev llvm-dev
```

渲染建置使用 rustls。渲染加 stealth 的建置使用
wreq/BoringSSL，因此需要上述額外建置工具。

## 快速上手

### 抓取頁面

```bash
# 取得頁面標題
obscura fetch https://example.com --eval "document.title"

# 抽出所有連結
obscura fetch https://example.com --dump links

# 渲染 JavaScript 並 dump HTML
obscura fetch https://news.ycombinator.com --dump html

# 把 dump 或 eval 輸出寫入檔案
obscura fetch https://example.com --dump text --output page.txt

# 逐字串流出原始回應主體（二進位安全；繞過 JS/DOM 層）。
# 適合圖片、JSON、JS、CSS 等任何非 HTML 資源。
obscura fetch https://picsum.photos/200/300 --dump original > photo.jpg

# 列出頁面將抓取的所有子資源 URL（NDJSON；每個資產一筆）
obscura fetch https://example.com --dump assets

# 透過 HTTP 或 SOCKS 代理抓取
obscura --proxy socks5://127.0.0.1:1080 fetch https://example.com --dump text

# 等待動態內容
obscura fetch https://example.com --wait-until networkidle0

# 為慢速或故障頁面限制導覽時間
obscura fetch https://example.com --timeout 10

# 把穩定後的頁面存成 PNG
obscura fetch https://example.com --screenshot page.png

# 截圖 flag 也有簡寫
obscura fetch https://example.com -s page.png
```

## 渲染

官方 release 壓縮包與 Docker 映像檔都包含渲染引擎。
它提供 CSS 布局與繪製、視口與整頁截圖、隨捲動感知的 fixed/sticky 幾何、
以活動驅動的 CDP 串流擷取，以及不啟動 Chromium 的光柵 PDF 匯出。

```javascript
await page.setViewport({ width: 1440, height: 1000 });
await page.goto('https://example.com', { waitUntil: 'load' });
await page.screenshot({ path: 'page.png', fullPage: true });
await page.pdf({ path: 'page.pdf', format: 'A4', printBackground: true });
```

目前實作涵蓋 block、inline、flex、grid、table、float、
positioning、overflow、transform、文字、圖片、SVG、canvas、背景、邊框與
動畫路徑。它仍是一套持續演進的獨立
引擎：長尾 CSS、部分 Web API、媒體播放、合成器效果與
平台字型光柵化可能與 Chromium 不同。既有的
[Puppeteer](docs/Use-with-Puppeteer.md)、
[Playwright](docs/Use-with-Playwright.md) 與
[MCP](docs/Use-the-MCP-server.md) 指南涵蓋它們的擷取 API 與限制。

### CJK 與自訂字型

**改了什麼**

- 新增 `cjk` cargo feature（release 壓縮包與 Docker 映像檔皆已開啟）。
  開啟後，二進位內嵌兩個字面作為 glyph 層級的 fallback：
  **Noto Sans CJK SC** 與 **Noto Sans CJK TC**，Regular 字重，SIL OFL 1.1
  （各約 16 MB）。
- 新增全域 `--fonts <PATH>` flag 與 `OBSCURA_FONTS_DIR` 環境變數，
  執行期從目錄載入額外字型檔案，補上內嵌字面沒覆蓋的文字系統。

**為什麼這麼做**

Obscura 刻意**不載入任何系統字型**。這讓布局在任何機器上都逐位相同、
啟動瞬間完成，但代價是中文與日文文字會渲染成豆腐塊（空方框）——
對 Obscura 的核心用途之一（爬取 CJK 語言網站）是致命的。
這個修法刻意**不**把系統字型重新引入：

- **不掃描字型系統。** 走 fontconfig 或 `~/.fonts` 會讓布局依賴 host、
  破壞跨機器決定性、並增加啟動成本。CJK 字面改放進二進位裡。
- **不改 shaping 邏輯。** cosmic-text 的 `Shaping::Advanced` 本來就會
  對每個 glyph 在其字型庫的所有字面間 fallback。CJK 字面只是加入
  這個庫：內嵌拉丁字面覆蓋的字碼繼續用 Liberation/DejaVu，只有缺的
  glyph 才落到 CJK 字面。拉丁布局逐位不變。
- **性能依然受保護。** 該 feature 預設關閉，`render`-only 的二進位
  保持小約 30 MB。此外 SVG 光柵化器的擴展字型庫（同樣帶著 CJK
  字面）採延遲建置，只在頁面真的有 inline SVG 文字時才建立，一般
  頁面為這 32 MB 字型資料付出零成本。

**你能獲得什麼**

- 中文（簡體與繁體）、日文漢字與假名、全形標點都以真實字形渲染——
  不需要系統字型，也不需要頁面自帶 webfont。
- 中日英混排文字獲得真實的布局度量：advance 寬度與行高來自實際
  字形，而非豆腐塊。
- 下游全部自動生效、零額外設定：`obscura fetch ... --screenshot`、
  CDP 截圖與串流、PDF 匯出，以及 MCP 的 `browser_screenshot` /
  `browser_pdf` 工具。

**限制與逃生通道**

- 只內嵌 Regular 字重：粗體 CJK 以正常字重渲染（不做假粗體）。
- 內嵌字面不覆蓋韓文 Hangul。
- 內嵌字面缺的任何字型，都把 Obscura 指向一個字型檔案目錄即可。
  掃描非遞迴、按檔名排序、接受 `ttf`/`otf`/`ttc`/`woff`/`woff2`；
  無法解析的檔案會跳過並警告。這是明確的 opt-in：布局會隨該目錄
  內容而變，這是刻意留下的、跳出「只靠內嵌字面」決定性的逃生通道。

```bash
# flag，可放在子命令前後
obscura --fonts /path/to/fonts fetch https://example.com -s page.png

# 或用環境變數（對 fetch、serve、scrape、mcp 皆生效）
OBSCURA_FONTS_DIR=/path/to/fonts obscura fetch https://example.com -s page.png
```

```bash
obscura serve --port 9222

# 搭配 stealth 模式（反偵測 + 追蹤器封鎖）
obscura serve --port 9222 --stealth
```

### 並列爬取

```bash
obscura scrape url1 url2 url3 ... \
  --concurrency 25 \

# 壓掉 stderr 的爬取進度，讓輸出對腳本友善
```

## Stealth 模式

以 `--features render,stealth` 建置，再用全域 `--stealth` flag 在執行期啟用。stealth 建置包含完整的渲染引擎；啟用 stealth 不會移除截圖、串流、PDF、CDP 或 MCP 功能。

### 反指紋
- 每 session 指紋隨機化（GPU、螢幕、canvas、音訊、電量）
- 真實的 `navigator.userAgentData`（Chrome 145，高熵值）
- 分發的事件 `event.isTrusted = true`
- 隱藏內部屬性（`Object.keys(window)` 安全）
- 原生函式掩蔽（`Function.prototype.toString()` → `[native code]`）
- `navigator.webdriver = undefined`（與真實 Chrome 一致）

### 追蹤器封鎖
- 封鎖 3,520 個網域
- 擋掉分析、廣告、遙測與指紋腳本
- 完全阻止追蹤器載入
- `--stealth` 時自動啟用

## CDP API

Obscura 為 Puppeteer/Playwright 相容性實作了 Chrome DevTools Protocol。

| Domain | Methods |
|--------|---------|
| **Target** | createTarget, closeTarget, attachToTarget, createBrowserContext, disposeBrowserContext |
| **Page** | navigate, getFrameTree, lifecycleEvents, captureScreenshot, start/stopScreencast, printToPDF |
| **Runtime** | evaluate, callFunctionOn, getProperties, addBinding |
| **DOM** | getDocument, querySelector, querySelectorAll, getOuterHTML, resolveNode |
| **Network** | enable, setCookies, getCookies, setExtraHTTPHeaders, setUserAgentOverride |
| **Fetch** | enable, continueRequest, fulfillRequest, failRequest（即時攔截）、takeResponseBodyAsStream |
| **IO** | read, close（分塊串流大型回應主體） |
| **Storage** | getCookies, setCookies, deleteCookies |
| **Input** | dispatchMouseEvent, dispatchKeyEvent |
| **LP** | getMarkdown（DOM 轉 Markdown） |

要下載大型資源又不想產生一個巨大的 `Network.getResponseBody` blob，就呼叫 `Fetch.takeResponseBodyAsStream`，再用 `IO.read` / `IO.close` 分塊讀取。超過快取上限（`OBSCURA_NETWORK_BODY_BUFFER_BYTES`，預設 2 MiB）的回應主體不會被保留，所以打算串流大型下載時要調高該上限。

## CLI 參照

### 調整 V8

Obscura 直接內嵌 V8。用 `--v8-flags` 把原始 flag 傳給 V8，語法與 Chromium 的 `--js-flags` 和 Node 的指令列 flag 相同。最常見的用途是調高堆積上限，修掉 JS 重度頁面的 `JavaScript heap out of memory`：

```bash
obscura --v8-flags "--max-old-space-size=4096" fetch <url>
```

### 重度 SPA（腳本執行預算）

Obscura 為頁面的腳本執行階段設上限，讓單個慢速或掛死的頁面無法卡住 worker。預設預算 30 秒；提前跑完的頁面立即回傳，所以上限只影響還在跑的頁面。非常重的 React/Vue/Angular SPA 在慢網路上可能需要更多時間啟動才會發出資料請求。用 `OBSCURA_SCRIPT_DEADLINE_MS`（毫秒）調高預算，並在你的 CDP client 搭配對應的導覽 timeout：

```bash
OBSCURA_SCRIPT_DEADLINE_MS=60000 obscura serve --port 9222
```

### `obscura serve`

啟動 CDP WebSocket server。

| Flag | 預設值 | 說明 |
|------|--------|------|
| `--port` | `9222` | WebSocket 埠 |
| `--proxy` | — | HTTP/SOCKS5 代理 URL |
| `--stealth` | 關 | 啟用反偵測 + 追蹤器封鎖 |
| `--workers` | `1` | 並列 worker 行程數 |
| `--obey-robots` | 關 | 遵守 robots.txt |

### `obscura fetch <URL>`

抓取並渲染單一頁面。

| Flag | 預設值 | 說明 |
|------|--------|------|
| `--dump` | `html` | 輸出：`html`、`text`、`links`、`markdown`、`assets`（頁面參考的所有子資源 URL 的 NDJSON）或 `original`（原始回應主體） |
| `--eval` | — | 要評估的 JavaScript 運算式 |
| `--wait-until` | `load` | 等待：`load`、`domcontentloaded`、`networkidle0` |
| `--timeout` | `30` | 導覽時間上限（秒） |
| `--wait` | 自適應，最高 `5` | 載入後穩定；明確給值則為固定秒數延遲 |
| `--selector` | — | 等待 CSS selector |
| `-s`、`--screenshot` | — | 寫出 PNG 截圖（單一 URL；需啟用渲染的建置） |
| `--stealth` | 關 | 反偵測模式 |
| `--output` | — | 把 dump 或 eval 輸出寫入檔案 |
| `--quiet` | 關 | 壓掉 banner |
| `--proxy` | — | 繼承的全域 HTTP/SOCKS5 代理 URL |
| `--fonts` | — | 繼承的全域額外 fallback 字型目錄（見 CJK 與自訂字型） |

### `obscura scrape <URL...>`

以 worker 行程並列爬取多個 URL。

| Flag | 預設值 | 說明 |
|------|--------|------|
| `--concurrency` | `10` | 並列 worker 數 |
| `--eval` | — | 每頁的 JS 運算式 |
| `--format` | `json` | 輸出：`json` 或 `text` |
| `--quiet` | 關 | 壓掉 stderr 的爬取進度 |
| `--proxy` | — | 繼承的全域 HTTP/SOCKS5 代理 URL，傳給所有 worker |
| `--fonts` | — | 繼承的全域字型目錄，轉發給每個 worker |

## MCP（Model Context Protocol）

Obscura 內建 MCP server，把瀏覽器自動化工具暴露給 AI agent（Claude Desktop、Cursor 等）。

### 啟動

**stdio**（預設）— 給 Claude Desktop 與以子行程啟動的 MCP client：

```bash
obscura mcp
```

**HTTP** — 給走網路連線的 client：

```bash
obscura mcp --http --port 8080
# endpoint: http://127.0.0.1:8080/mcp
```

選配 flag（兩種傳輸皆有）：

| Flag | 說明 |
|------|------|
| `--proxy <URL>` | HTTP/SOCKS5 代理 |
| `--user-agent <UA>` | 自訂 User-Agent 字串 |
| `--stealth` | 啟用反偵測模式 |

### Claude Desktop 設定

```json
{
  "mcpServers": {
    "obscura": {
      "command": "obscura",
      "args": ["mcp"]
    }
  }
}
```

### 工具

| Tool | 說明 |
|------|------|
| `browser_navigate` | 導覽到 URL（`url`，選配 `waitUntil`：`load` / `domcontentloaded` / `networkidle0`） |
| `browser_snapshot` | 回傳目前頁面 URL、標題、可讀正文文字與元素參考 |
| `browser_screenshot` | 以 MCP PNG 圖片回傳目前頁面（需啟用渲染的建置） |
| `browser_pdf` | 以內嵌 PDF 資源回傳目前頁面（需啟用渲染的建置） |
| `browser_click` | 以目前 snapshot 參考或 CSS selector 點擊 |
| `browser_fill` | 以參考或 selector 設定輸入值（觸發 `input` + `change`） |
| `browser_type` | 向輸入附加文字 |
| `browser_press_key` | 分發鍵盤事件（`key`，選配 `selector`） |
| `browser_select_option` | 以 value 或文字選擇 `<option>` |
| `browser_evaluate` | 評估 JavaScript 運算式並回傳結果 |
| `browser_wait_for` | 等待 CSS selector 出現（`selector`，選配 `timeout`（秒）） |
| `browser_network_requests` | 列出目前頁面發出的網路請求 |
| `browser_console_messages` | 回傳頁面記錄的 console 訊息 |
| `browser_close` | 關閉頁面並重置瀏覽器狀態 |

MCP server 提供靜態圖片與 PDF 輸出。需要串流的 `Page.startScreencast` 協定時請用 CDP。
